# dotfiles

macOS terminal environment setup.

## Fresh machine setup

```bash
git clone https://github.com/dplane2720/dotfiles.git ~/dotfiles
cd ~/dotfiles
./install.sh
```

After install, update `~/.gitconfig` with your name and email:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

> Miniforge/conda is not included — install separately if needed: https://github.com/conda-forge/miniforge
